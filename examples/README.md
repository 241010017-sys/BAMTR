# Synthetic examples

Every record in `synthetic/` and `inference/` was generated by
`scripts/generate_synthetic.py`. These files contain no source user IDs or
source location records. They only demonstrate the input schema and software
workflow. Metrics from these fixtures are not research results.

`synthetic/` contains six daily CSVs with the same `ID,lng,lat,time,tid` columns
as the supplied data. `inference/observations.csv` contains retained observations
for one synthetic user-day. `inference/queries.csv` contains only that day's
missing timestamps, without target coordinates or stay labels.

To regenerate the fixtures, run from the repository root:

```bash
python scripts/generate_synthetic.py
```
